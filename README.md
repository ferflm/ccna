# 📡 CCNA Packet Tracer Labs

Repositorio donde documentaré y versionaré mis laboratorios de Packet Tracer como parte de mi preparación para la certificación CCNA (Cisco Certified Network Associate).

Los laboratorios provienen del curso [Cisco CCNA 200-301 – The Complete Guide to Getting Certified - Neil Anderson](https://www.udemy.com/share/1013g83@7EIxuEh1y2JZLcPWEMqCJP2HB-rAPM1bGt7YDGfBhJaJJGTL1toidnFWMkgi2ogz4Q==/)

---

## 🎯 Objetivo

Este repositorio tiene como propósito:

- Reforzar conceptos de redes mediante práctica real.
- Documentar configuraciones paso a paso.
- Construir un portafolio técnico demostrable.
- Simular escenarios similares a los que pueden aparecer en el examen CCNA.

---

## 🧠 Temas que cubriré

Los laboratorios estarán alineados con el temario oficial de CCNA, incluyendo:

- Network Fundamentals  
- Modelos OSI & TCP/IP  
- Subnetting (CIDR y VLSM)  
- VLANs & Trunking  
- Inter-VLAN Routing  
- Static Routing  
- OSPF  
- ACLs  
- NAT  
- DHCP  
- WAN Technologies  
- Fundamentos de Seguridad de Red  

---

## 🛠️ Herramientas utilizadas

- Cisco Packet Tracer  
- CLI de dispositivos Cisco  
- Documentación en Markdown  
- Diagramas de topología  

---

## 📂 Estructura del repositorio

Cada laboratorio tendrá su propia carpeta con la siguiente estructura:

```
/lab-name
 ├── topology.pkt
 ├── README.md
 ├── diagram.png
 └── configs/
```

El README de cada laboratorio incluirá:

- 🎯 Objetivo del laboratorio  
- 🗺️ Topología  
- 🧮 Esquema de direccionamiento IP  
- ⚙️ Configuración paso a paso  
- ✅ Pruebas de conectividad  
- 📚 Conceptos reforzados
